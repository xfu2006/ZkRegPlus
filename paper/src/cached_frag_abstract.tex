Zero Knowledge Proof (ZKP) has been useful in proving
DNS blocklist, redacted emails, malware freedom, and
intrusion detection. In this paper, we present ZkregPlus,
which leverages the pre-processed lookup arguments.
We first provide several constructions for
lookup of field elements and group elements.
We then provide a pure algebraic protocol
for proving that a string hiding in a Pedersen
vector commitment is contained in a regular language.
The prover cost is independent of specification size,
and linear on the input string length, and
the verifier complexity is logarithm.
We provide further improvement by leveraging caching
of frequently used fragements in look-up argument,
and skipping arbitrary strings (which cause huge
automata size) in practice. We fully implmenet
the protocol and show greater concrete performance
with prior works.
