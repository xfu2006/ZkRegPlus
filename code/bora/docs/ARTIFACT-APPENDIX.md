## Abstract

BORA (internally `zkregplus`) is a *bulk regex zero-knowledge
non-membership* (zk-BuNR) system: it proves that a committed file does
**not** match any regex in a large published collection (e.g. the ~38k-rule
ClamAV rule base), at near-linear cost in the file length. The artifact is
the reference Rust implementation plus the data-installers and one-shot
runners behind the paper's evaluation. It combines a tiered approximation
(CP / SDE / DFA) discharge with a folding-based prover (`FoldPot`: a
modified SuperNova + CycleFold with lookups) and a Groth16 decider over the
BN254/Grumpkin curve cycle. Evaluators can run a self-contained ~40 s demo
on a laptop; the three full paper datasets (MAL / DNA / DLP) are
large-RAM, many-hour runs.

## Description & Requirements

### Security, privacy, and ethical concerns

- The data installer downloads **real malware-scan targets** (CentOS
  binaries, scanned against the ClamAV rule base) and the **real Enron
  e-mail corpus**, which contains **personal information (PII)**.
  Evaluators should run inside an isolated VM or container.
- The artifact **does not execute** any downloaded binary; it only reads
  their bytes as scan input. There are **no destructive side effects** on
  the host. Network egress occurs **only during `INSTALL.py`**: to CMU
  (Enron corpus) and Google Drive (sample bundles).
- Data provenance: the Enron corpus is the public CMU release dated
  2015-05-07 (`https://www.cs.cmu.edu/~./enron/`); the malware rules are
  ClamAV 0.103.11; the MS-DLP SIT patterns are reconstructed regex sets.

- **Rust 1.76.0** — pinned in `rust-toolchain`; do **not** change it (the

## Set-up

### Installation

```bash
# from the repo root
python3 scripts/INSTALL.py --toolchain      # Rust 1.76.0 + build deps
python3 scripts/INSTALL.py --data all       # or: email | dna | binexec
RUSTFLAGS="-C link-args=-fuse-ld=lld -Awarnings" cargo build --release
```

### Basic Test

The fast "kick the tires" check (README section 7):

```bash
RUSTFLAGS="-C link-args=-fuse-ld=lld -Awarnings" \
  cargo test -p zkregplus --release --lib -- \
  zkp_driver::tests_zkp_driver::test_zkreg_main --exact --nocapture
```

Runs the `small_data` end-to-end ZK proof in ~30-40 s (~7 GB RAM) and

### Experiments

All full runs go through one menu; each self-detaches into the background
(survives logout, no `nohup` needed) and, on any exit, packs exactly **one**
result bundle at `/tmp/paper_data_<key>_<ts>/paper_data_<key>_BUNDLE_<ts>.tgz`.
Follow a run with `tail -f` on the daemon-log path it prints.

**E0 - Basic test (small).** [Human: ~1 min] [Compute: ~40 s] [Disk: ~7 GB
RAM, negligible disk]
- *How to:* run the Basic Test command above.
- *Results:* an end-to-end ZK proof succeeds; report under
  `data/small_data_set/reports/`. Sanity only; not tied to a paper number.

**E1 - DNA (C3).** [Human: minutes] [Compute: ~hours] [Disk: DNA dataset
~6.6 GB + large RAM]
- *Preparation:* `python3 scripts/INSTALL.py --data dna`.
- *Execution:* `python3 scripts/PAPER_DATA.py --run dna`.
- *Results:* `data/paper_data/dna/reports/report_zk.dat`; compare against
  paper Tables 1-2.

**E2 - MAL / ClamAV (C2).** [Human: minutes] [Compute: ~5-8 h] [Disk:
binexec + ClamAV DB; ideally ~1 TB RAM / 8 NUMA nodes; rebuilds ~40 GB DB]
- *Preparation:* `python3 scripts/INSTALL.py --data binexec` (the ClamAV
  DB rebuilds on first run; `--clam-reuse-db` skips the ~2 h rebuild once a
  cache exists).
- *Execution:* `python3 scripts/PAPER_DATA.py --run clam` (8-job 4+4
  two-process NUMA run; part 2 emits one verified Groth16 proof).
- *Results:* `data/debug/full_clamav/reports/report2.dat` plus one verified
  batch proof; compare against paper Tables 1-3 / section 7.4-7.6.

**E3 - DLP / Enron (C4).** [Human: minutes] [Compute: ~5-6 h] [Disk: email
dataset ~3.8 GB + large RAM / NUMA]
- *Preparation:* `python3 scripts/INSTALL.py --data email`.
- *Execution:* `python3 scripts/PAPER_DATA.py --run dlp` (8-job 4+4
  two-process NUMA run; fold-only by default, `--dlp-proof` to also emit +
  verify the single Groth16 proof).
- *Results:* `data/paper_data/dlp/report/report.dat`; compare against paper
  Tables 1, 2, 4.
